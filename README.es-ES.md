

## 🌟 Awesome LLM Apps

Bienvenido a **Awesome LLM Apps** – una colección curada de fantásticas aplicaciones de LLM construidas con Generación Aumentada por Recuperación (RAG) y agentes de IA. Este repositorio muestra aplicaciones que utilizan modelos de OpenAI, Anthropic, Google e incluso modelos de código abierto como LLaMA, que puedes ejecutar localmente.

### 📂 Proyectos Destacados

1. #### 📚✨ AIBookWriter
   AIBookWriter es una aplicación web de Streamlit de vanguardia que aprovecha el poder de la IA para crear automáticamente libros completos a partir de simples prompts. ¡Es la herramienta perfecta para autores, creadores de contenido, investigadores y cualquier persona que busque generar rápidamente contenido completo y estructurado! 📖💡🔍

2. #### 🤖💬 AI Chat Assistant
   ¡Bienvenido a AI Chat Assistant! Esta intuitiva aplicación de Streamlit aprovecha los avanzados modelos de lenguaje de Groq para ofrecer una experiencia de chat fluida. Con un diseño moderno y elegante y funciones potentes, es tu asistente de confianza para todas tus necesidades de interacción con IA.

3. #### 📈💼 AI Finance Agent
   ¡Bienvenido a AIFinanceAgent! Esta encantadora aplicación de Streamlit aprovecha el poder de la IA para comparar el rendimiento de dos acciones, generando informes detallados para guiar tus decisiones de inversión. Al aprovechar GPT-4 junto con datos de Yahoo Finance, obtendrás información valiosa que te ayudará a tomar decisiones informadas.

4. #### 🚀📈 AI Finance Agent
   (Nota: Proporcionaste dos entradas para AI Finance Agent. He incluido ambas, pero es posible que quieras diferenciarlas o combinarlas si se trata del mismo proyecto.)

5. #### 🗞️🗞️ AIJournalistAgent
   AIJournalistAgent es una aplicación de Streamlit que utiliza OpenAI GPT-4 para ayudar a crear artículos de alta calidad sobre cualquier tema. Agiliza el proceso de investigación, redacción y edición, haciendo que la creación de contenido sea más rápida y sencilla.

6. #### 🌍✈️ AITravelAgent
   POC de Abhishek: ¡Planifica y descubre viajes perfectos con Phidata y OpenAI utilizando prompts inteligentes! 🤖💡
   Este proyecto es una Prueba de Concepto (POC) de Abhishek, que utiliza Phidata y OpenAI para planificar y buscar viajes basándose en los prompts del usuario. El asistente de IA ayuda a los usuarios a organizar sus viajes perfectos encontrando los mejores vuelos, hoteles y actividades populares en su destino deseado. 🧳🌴

7. #### 🎥✨ AIYouTubeHighlightGenerator
   ¡Transforma el contenido de YouTube en fragmentos cautivadores con la magia de la IA! 🚀🤖
   AIYouTubeHighlightGenerator es una aplicación web de Streamlit de vanguardia que aprovecha el poder de la IA para crear automáticamente fragmentos atractivos a partir de transcripciones de videos de YouTube. ¡Es la herramienta perfecta para creadores de contenido, especialistas en marketing, investigadores y cualquier persona que busque destilar rápidamente la esencia de videos largos! 🎬💡🔍

### 🚀 Primeros Pasos
1. **Clona el repositorio**:
    ```bash
    git clone https://github.com/Abhishek-yadv/AwesomeLLMApps
    ```
2. **Navega al directorio del proyecto deseado**:
    ```bash
    cd AwesomeLLMApps/AIFinanceAgent
    ```
3. **Instala las dependencias requeridas**:
    ```bash
    pip install -r requirements.txt
    ```
4. **Sigue las instrucciones específicas del proyecto** en el archivo README.md de cada proyecto para configurar y ejecutar la aplicación.
